**🔢 Algorithm Performance:**

| Algorithm | Dimensionality | Query Time | Complexity |
|---|---|---|---|
| **HNSW Graph** | Any D | ~18 µs | $O(\log N)$ |
| **KD-Tree** | Low D (≤20) | ~45 µs | $O(\log N)$ → $O(N)$ at high D |

**💻 Key Code — The HNSW Layer Formula:**
```cpp
// Probabilistic skip-list layer assignment — mathematical elegance in 2 lines
int randLevel() {
    std::uniform_real_distribution<float> u(0.0f, 1.0f);
    return (int)std::floor(-std::log(u(rng)) * mL);
    // P(reach layer l) = M^(-l) — exponential decay, just like a skip list!
}
```

### HNSW — Hierarchical Navigable Small World

Built from scratch, including every piece:
- **Multi-layer probabilistic graph**: `P(node reaches layer l) = M^(-l)`
- **Greedy routing** on upper sparse layers → $O(\log N)$ spatial navigation
- **Beam search** at Layer 0 with tunable `ef` parameter for recall-latency tradeoff
- **Bidirectional edge formation + pruning** at insertion time
- **Thread-safe via `std::lock_guard`** — safe under concurrent REST requests

### KD-Tree — Space Partitioning

- **Axis-aligned hyperplane splitting**: `axis = depth % D`
- **Max-heap** for dynamic k-NN candidate tracking during backtracking
- **Pruning**: skip farther subtree if `|q[axis] - node[axis]| ≥ heap.top().distance`
- **Curse of Dimensionality**: Proven empirically — KD-Trees degrade to $O(N)$ for $D > 20$

### Distance Metrics

| Metric | Formula | Best Use Case |
|---|---|---|
| Euclidean $L_2$ | $\sqrt{\sum(u_i - v_i)^2}$ | Physical/spatial data |
| Cosine | $1 - \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|}$ | Text & semantic embeddings |
| Manhattan $L_1$ | $\sum\|u_i - v_i\|$ | Sparse or grid-based data |
